# Research agent

> **Document status:** Active
> **Last source review:** 2026-08-29

**Scope:** a question that has no decision behind it yet — a new world family, a
new dependency, a direction that may need to change. The output is an argument,
not an implementation.

## Reading order

1. [../evolution/README.md](../evolution/README.md), then whichever prior
   research is nearest your question. Every one of them shows the shape this
   project expects: alternatives named, rejections justified, licences checked
   by hand.
2. [../knowledge/](../knowledge/README.md) for whatever the change would touch.
   Research grounded in what someone remembers the system doing is worth
   nothing here.
3. [../memory/](../memory/README.md) — specifically for whether this question
   has been answered before and the answer went wrong.

## Do not read

`../plans/` first. A plan states a decision; reading it before you have formed a
view is how research turns into a justification of the status quo. Read it
afterwards, to say explicitly what your conclusion changes about it.

## Rules specific to this work

**Nothing you write is approved by having been written.** Every document in
`evolution/` opens by saying so. A research document that reads like a plan will
eventually be implemented as one.

**Check licences yourself, file by file.** `ocean-family-research.md` is the
model: it verified CC0 assets and public-domain audio individually, and the
licence wall it found re-scoped an entire family. A licence stated on a
collection page is not a licence on an asset.

**Read the source file by file for a reuse claim.** The same document's reuse
inventory is why the ocean family cost what it did rather than twice that. "We
can probably reuse the forest rig" is not a finding.

**Say what would falsify you.** The most valuable documents in `memory/` are the
ones where a measurement contradicted a prediction. That only happens when the
prediction was specific enough to be contradicted.

## Done means

A document in [../evolution/](../evolution/README.md) with a `Document status`
that says plainly it is research and not approved; the alternatives you rejected
and why; the evidence you actually checked, cited by path; and one section
saying what this changes about the current plan — including "nothing", if that
is the honest answer.

When the conclusion is accepted, it graduates: a new or amended document in
[../plans/](../plans/README.md), while the research stays here as the argument
for it.
